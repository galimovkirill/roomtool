# Flow пользователя

## Регистрация и вход

- неавторизованный пользователь попадает на страницу `/login`
- на странице `/login` доступны две формы: «Войти» и «Зарегистрироваться»
- при регистрации пользователь вводит email и пароль; при успехе автоматически входит и переходит на `/files`
- при входе пользователь вводит email и пароль; при успехе переходит на `/files`
- ошибки API (неверный пароль, email уже занят и т.д.) переводятся на русский и отображаются под формой
- авторизация хранится в cookie `access_token` (15 мин) + `refresh_token` (7 дней, ротируется)
- при истечении access_token сессия тихо обновляется через `/api/v1/auth/refresh`

## Выход

- в шапке приложения (AppHeader) — дропдаун с email пользователя и кнопкой «Выйти»
- при нажатии «Выйти» cookies очищаются, пользователь перенаправляется на `/login`

## Страница файлов (/files)

- при открытии пользователь видит список своих сцен в виде карточек
- карточка отображает: имя сцены, дату последнего изменения
- над списком — кнопка «Создать сцену»: создаёт новую сцену на сервере и открывает её в редакторе
- двойной клик по имени карточки — переименование сцены (inline input, сохраняется на сервере)
- контекстное меню карточки (три точки): «Открыть», «Переименовать», «Дублировать», «Удалить»
- «Дублировать» создаёт копию сцены со всеми данными и именем «{имя} — копия»
- если сцен нет — отображается заглушка с кнопкой «Создать первую сцену»
- ошибки загрузки отображаются с кнопкой «Повторить»

## Открытие приложения (редактор)

- если ширина экрана пользователя менее 1024px — вместо приложения отображается уведомление о неподдерживаемом устройстве
- при открытии `/editor/:id` загружается сцена с сервера; если сцена не найдена — редирект на `/files`
- пользователь видит сцену, которая выглядит как обычная жилая комната с двумя стенами и полом (4000 × 4000 × 3000 мм)
- справа пользователь видит перечень элементов, сгруппированных по категориям, которые он может добавлять на сцену нажатием

## Добавление элементов

- пользователь кликает на элемент в правой панели — элемент появляется в центре комнаты
- если в центре уже стоит другой элемент — новый всё равно добавляется в центр, коллизия проверяется только при перемещении

## Перемещение и поворот элементов

- пользователь выбирает элемент кликом — появляется гизмо с тремя осями для перемещения
- на сцене пользователь может перемещать элементы по трём осям
- при попытке разместить элемент в позиции, занятой другим (коллизия), перемещение откатывается на последнюю валидную позицию и отображается уведомление
- при выборе элемента в ленте появляются кнопки: повернуть влево, повернуть вправо, удалить

## Панель свойств

- при двойном клике на элемент в 3D или «Редактировать» в контекст-меню слоёв — панель справа заменяется на настройки характеристик этого элемента (ширина, высота, глубина, прочие параметры)
- обычный одиночный клик открывает выделение и гизмо, но не открывает свойства
- при нажатии на крестик в панели свойств — панель закрывается, выделение остаётся

## Удаление

- при нажатии на кнопку удаления в ленте — выбранный элемент удаляется со сцены

## Undo / Redo

- пользователь может отменить последнее действие через Ctrl+Z (или Cmd+Z на macOS)
- пользователь может повторить отменённое действие через Ctrl+Y (или Cmd+Y на macOS)
- поддерживаемые для отмены действия: добавление, удаление, перемещение, поворот, изменение свойств

## Режимы отображения сцены

- над сценой расположены кнопки "3D" и "2D"
- в режиме 3D: перспективная камера, вращение и зум
- в режиме 2D: ортографический вид сверху, отображаются размеры элементов, вращение камеры отключено

## Автосохранение

- сцена автоматически сохраняется на сервер через 1,5 секунды после последнего изменения
- в ленте отображается индикатор статуса: «Сохранено» / «Сохранение…» / ошибка сохранения
- данные также кэшируются в localStorage для быстрого восстановления при перезагрузке страницы
