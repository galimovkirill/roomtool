# Flow пользователя

## Открытие приложения

- если ширина экрана пользователя менее 1024px — вместо приложения отображается уведомление о неподдерживаемом устройстве
- при открытии страницы пользователь видит перед собой сцену, которая выглядит как обычная жилая комната с двумя стенами и полом (4000 × 4000 × 3000 мм)
- справа пользователь видит перечень элементов, сгруппированных по категориям, которые он может добавлять на сцену нажатием

## Добавление элементов

- пользователь кликает на элемент в правой панели — элемент появляется в центре комнаты
- если в центре уже стоит другой элемент — новый всё равно добавляется в центр, коллизия проверяется только при перемещении

## Перемещение и поворот элементов

- пользователь выбирает элемент кликом — появляется гизмо с тремя осями для перемещения
- на сцене пользователь может перемещать элементы по трём осям
- при попытке разместить элемент в позиции, занятой другим (коллизия), перемещение откатывается на последнюю валидную позицию и отображается уведомление
- при выборе элемента поверх него появляются кнопки: повернуть влево, повернуть вправо, удалить

## Панель свойств

- при нажатии на элемент на сцене панель справа заменяется на настройки характеристик этого элемента (ширина, высота, глубина, прочие параметры)
- при нажатии на пустое место на сцене выделение снимается, панель справа возвращается к каталогу элементов

## Удаление

- при нажатии на кнопку удаления у выбранного элемента — элемент удаляется со сцены

## Undo / Redo

- пользователь может отменить последнее действие через Ctrl+Z
- пользователь может повторить отменённое действие через Ctrl+Y
- поддерживаемые для отмены действия: добавление, удаление, перемещение, поворот, изменение свойств

## Режимы отображения сцены

- над сценой расположены кнопки "3D" и "2D"
- в режиме 3D: перспективная камера, вращение и зум
- в режиме 2D: ортографический вид сверху, отображаются размеры элементов, вращение камеры отключено
