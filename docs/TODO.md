## Тест логики координат SceneOverlay

Логика вычисления координат в `SceneOverlay` (центроид выбранных элементов, вычитание `height/2` для Y) реализована внутри Zustand-селектора компонента. `SceneOverlay` — не R3F-компонент, его можно тестировать в jsdom.

Что стоит покрыть:
- нет выделения → `coords` равен `null`, блок не рендерится
- одиночный элемент → `Y = position[1] − height/2`, элемент «стоит на полу» при Y=0
- мультивыбор → показывается центроид (среднее по каждой оси)

Вариант реализации: вынести функцию вычисления координат в `utils/coordsFromSelection.ts` и покрыть её юнит-тестом отдельно от компонента.

## UX: индикация центроида при мультивыборе

При выборе нескольких элементов в LayersPanel блок координат показывает усреднённую позицию (центроид), а не координату конкретного элемента. Это не очевидно пользователю.

Варианты:
- добавить tooltip на блок координат: «Центр выделения»
- показывать метку рядом с координатами (например, «∅ X 450 Y 0 Z 0»)
- не показывать координаты при мультивыборе вовсе (упростить)

Решение зависит от того, насколько часто пользователи будут работать с мультивыбором через LayersPanel.
