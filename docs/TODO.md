## Вложенные группы элементов

Необходимо добавить возможность создавать вложенные группы элементов во вкладке "Слои".

Например, у нас есть группа "Шкаф". Эта группа может состоять из нескольких подгрупп – "Ящик шкафа 1", "Ящик шкафа 2", "Двери" и прочие. Все они могут быть вложены в группу "Шкаф".

Если я выберу несколько элементов из группы "Шкаф" и в диалоговом окне выберу "Создать группу", то она создастся на верхнем уровне, вместо того, чтобы быть вложенной в "Шкаф".

Вложенность элементов может быть бесконечной.
