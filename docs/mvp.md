# Цель MVP

Разработать небольшое клиентское приложение (только frontend-часть) для проектирования шкафов.

# Целевая аудитория

Дизайнеры мебели (шкафов)

# Ключевая ценность

Удобная работа с моделированием шкафов и их гибкая настройка

# Must have

- сцена, на которой отображаются элементы в виде 3D модели
- настройка отображения сцены (повороты сцены)
- перечень элементов, которые могут быть перенесены на сцену
- настройка расположения элементов внутри сцены (перемещения по трём осям, повороты элементов в плоскости)
- удаление элементов со сцены
- настройка определённых параметров конкретного элемента (высота, ширина, глубина и прочие параметры, специфичные для элемента)
- сцена может переключаться между 2D (вид сверху в виде чертежа) и 3D режимами
- отмена и повтор действий (Undo / Redo через Ctrl+Z / Ctrl+Y)
- запрет коллизий: элементы не могут пересекаться друг с другом; при попытке разместить элемент в позиции, занятой другим, перемещение отменяется и отображается уведомление

# Nice to have

- множественный выбор элементов на сцене

# Не делать сейчас

- не делать серверную часть, приложение является исключительно клиентским
- не добавлять авторизацию, регистрацию
- не добавлять возможность менять текстуры элемента
- не добавлять возможность скрывать элементы (все элементы либо видны, либо удалены со сцены)
- не сохранять состояние сцены между сессиями: при перезагрузке страницы сцена сбрасывается

# Единицы измерения

Все размеры в приложении задаются и отображаются в **миллиметрах (мм)**.
В 3D-сцене `1 unit = 1 мм`.

# Конфигурация сцены

Базовые параметры комнаты вынесены в конфигурационный файл `src/config/scene.ts`.
Это позволяет разработчику изменить размеры комнаты без правки компонентов.
Размеры по умолчанию: **4000 × 4000 × 3000 мм** (ширина × глубина × высота).

# Технические ограничения

- приложение работает только на десктопных устройствах
- минимальная поддерживаемая ширина экрана — **1024px**
- если ширина экрана пользователя меньше 1024px — вместо приложения отображается уведомление о неподдерживаемом устройстве
