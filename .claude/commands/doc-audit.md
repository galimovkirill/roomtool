Проведи аудит CLAUDE.md — сверь его с текущим состоянием кодовой базы и предложи конкретный diff.

## Что проверять

Аудит сверяет только то, что нельзя вычитать из кода:

1. **Структура файлов** — есть ли в `src/` новые файлы/директории, которых нет в CLAUDE.md? Удалены ли упомянутые?
2. **Каталог деталей** — сверь `src/catalog/items.ts` (список id, defaultDimensions) с таблицей в CLAUDE.md
3. **Типы** — сверь `src/types/index.ts` с описанием типов в CLAUDE.md
4. **Store** — сверь экспорты `src/store/sceneStore.ts` с упомянутыми полями и мутациями
5. **Конвенции** — проверь, что упомянутые файлы (`config/scene.ts`, `utils/collision.ts` и т.д.) существуют и экспортируют то, что написано
6. **Тесты** — сверь раздел «Тесты» CLAUDE.md с реально существующими `*.test.ts(x)` файлами
7. **Команды** — запусти `cat package.json | grep '"scripts"' -A 20` и сверь с разделом «Команды»

## Инструкция

1. Прочитай CLAUDE.md целиком
2. Прочитай ключевые файлы: `src/types/index.ts`, `src/catalog/items.ts`, `src/catalog/materials.ts`, `src/config/scene.ts`
3. Запусти:
   ```bash
   find src -name "*.ts" -o -name "*.tsx" | grep -v node_modules | sort
   find src -name "*.test.ts" -o -name "*.test.tsx" | sort
   cat package.json | python3 -c "import sys,json; s=json.load(sys.stdin)['scripts']; [print(f'{k}: {v}') for k,v in s.items()]"
   ```
4. Для каждого несовпадения сформируй пункт:
   - **Секция в CLAUDE.md** — что написано сейчас
   - **Что в коде** — что реально
   - **Предлагаемое исправление** — конкретный текст для замены

## Формат вывода

```
## Аудит CLAUDE.md — <дата>

### Расхождения найдены: N

#### 1. [Секция: Каталог деталей]
**Сейчас:** `hanging-rod` — 860 × 25 × 25
**В коде:** 860 × 30 × 30 (catalog/items.ts:42)
**Исправить:** обновить строку в таблице

...

### Актуально (проверено, совпадает): ...список разделов...
```

Если расхождений нет — написать «CLAUDE.md актуален, расхождений не найдено».

После вывода отчёта — спроси пользователя, применить ли найденные исправления.
