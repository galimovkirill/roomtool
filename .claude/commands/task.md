## Инструкция по выполнению задачи

1. Прочитай BACKLOG.md и найди блок нужной задачи
2. Прочитай промпт задачи — он содержит точные требования
3. Сверь с CLAUDE.md соглашения проекта (единицы, алиасы, стек)
4. Выполни все шаги из промпта строго по порядку
5. Если задача предполагает тесты — запусти `pnpm test` и убедись что они проходят
6. Если задача предполагает проверку в браузере — запусти `pnpm dev` и проверь через Playwright
7. Если задача предполагает `pnpm build` — запусти и убедись в отсутствии ошибок
