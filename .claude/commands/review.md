Запусти агента для ревью текущих изменений в репозитории.

## Что делать

1. Получи diff изменений: `git diff HEAD` (включает staged и unstaged). Если diff пустой — попробуй `git diff HEAD~1` (последний коммит).
2. Получи список изменённых файлов: `git status --short`.
3. Запусти агента через Agent tool (subagent_type: general-purpose) и передай ему весь контекст для ревью.

## Промпт для агента

Передай агенту следующее (подставив реальный diff и список файлов):

---

Ты — опытный senior-разработчик. Проведи код-ревью изменений в проекте RoomTool.

**Стек проекта:** React 18 + TypeScript (strict), Three.js + @react-three/fiber, Zustand, Tailwind CSS v4, Vitest.
**Соглашения:** 1 unit Three.js = 1 мм, размеры комнаты только из `src/config/scene.ts`, алиас `@/` для `src/`.

**Изменённые файлы:**
{FILE_LIST}

**Diff:**
```
{DIFF}
```

Проведи ревью по следующим категориям. Для каждой укажи: ✅ всё хорошо / ⚠️ есть замечания / ❌ критическая проблема.

1. **Корректность** — логика работает правильно, нет багов, edge cases обработаны
2. **Типобезопасность** — TypeScript используется строго, нет `any`, приведения типов обоснованы
3. **Соответствие соглашениям** — единицы измерения, импорты через `@/`, структура файлов
4. **Читаемость** — имена понятны, код самодокументирован, комментарии только там где нужны
5. **Тесты** — покрытие достаточное, тесты проверяют реальное поведение а не реализацию

По каждой найденной проблеме укажи:
- Файл и строка (если применимо)
- Описание проблемы
- Конкретное предложение по исправлению

В конце — итоговый вердикт: можно мержить / нужны правки / нельзя мержить.
